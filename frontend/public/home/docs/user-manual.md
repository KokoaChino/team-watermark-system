# 使用手册

### 1. 快速上手流程

1. 注册或登录账号
2. 完成团队准备（团队信息、邀请码、成员）
3. 在“模板列表/草稿区”制作并提交水印模板
4. 在“创建批量任务”页面上传图片并配置参数（可导入 Excel）
5. 前往“批量任务执行”查看进度并下载结果
6. 在“操作日志”复盘团队协作和任务结果

### 2. 账户模块
#### 2.1 注册与登录
- 注册支持：用户名、邮箱、密码、图形验证码、邮箱验证码
- 登录支持两种方式：
- 密码登录（账号 + 密码）
- 验证码登录（邮箱 + 邮箱验证码）

#### 2.2 找回密码

- 在“忘记密码”页面输入邮箱并获取验证码，验证通过后设置新密码

#### 2.3 修改资料与注销
- 可修改用户名、邮箱、密码
- 修改邮箱或密码后会自动退出登录，需要重新登录
- 注销账户会删除账号及关联数据，请谨慎操作

### 3. 团队管理
#### 3.1 团队概览
- 查看团队名称、点数余额、队长、成员列表
- 队长可修改团队名称
- 可从该页面发起点数充值

#### 3.2 邀请码管理
- 队长可生成邀请码，可设置有效期和最大使用次数
- 支持复制分享文本、查看邀请记录、手动失效邀请码

#### 3.3 加入/退出/成员管理
- 成员可通过邀请码文本加入其他团队
- 成员退出团队后会回到个人团队
- 队长可踢出成员、转让队长身份

### 4. 模板与字体
#### 4.1 模板列表
- 查看团队模板，支持按名称、创建者、时间筛选
- 支持新建模板、编辑模板
- 删除权限：队长或模板创建者可删除

#### 4.2 草稿区
- 配置底图：宽度、高度、背景色
- 配置水印层：可添加文字水印/图片水印，支持拖拽排序
- 实时预览：画布可视化查看效果，支持交互调整
- 保存草稿：可多次保存编辑进度
- 提交模板：可新建模板，或在编辑场景下选择“修改源模板”
- 冲突处理：若源模板已变化，可选择基于当前草稿新建模板

#### 4.3 字体管理
- 支持上传 `.ttf`/`.otf` 字体并用于文字水印
- 可按名称、类型、来源筛选
- 删除权限：队长可删除团队上传字体（系统字体不可删除）

### 5. 批量任务
#### 5.1 创建页：两步完成
1. 选择模板：在步骤一选择要使用的水印模板
2. 配置参数：在步骤二上传待处理图片，并设置每张图的水印输入、输出路径、文件名、拓展名

#### 5.2 Excel 导入规则
- 映射模式：按图片 ID 映射 / 按顺序映射
- 重复 ID 处理（ID 映射时）：报错终止 / 保留第一个 / 保留最后一个
- 异常字符处理：报错终止 / 放入 ERROR 文件夹 / 下划线替代。
- 覆盖策略：强制覆盖现有配置 / 仅补充空参数

#### 5.3 执行设置
- 文字水印：输入为空或绘制失败时，可选择“跳过”或“使用模板内容”
- 图片水印：输入为空或加载失败时，可选择“跳过”或“使用模板内容”

#### 5.4 执行页与结果处理
- 系统并发处理任务并展示实时进度、成功/失败数量
- 任务完成后可下载结果包（ZIP）
- 失败项支持下载原图并查看错误日志
- 若完成回调失败，可点击“重试完成任务”
- 可清除本次任务记录（会清理本地执行会话数据）

### 6. 点数与支付
- 点数按团队共享
- 计费规则：1 点 = ¥0.01（支付宝沙箱环境）
- 任务提交时预扣，完成后按成功数结算并返还剩余点数
- 充值成功后团队余额会更新

### 7. 日志中心
系统提供四类日志，均支持分页与筛选查询：

- 团队变更：邀请码、成员加入退出、队长转让、团队改名
- 水印资源：模板与字体的创建、修改、删除
- 点数流水：充值、预扣、返还明细
- 任务记录：任务编号、模板、成功失败统计、点数结算明细

### 8. 推荐操作顺序
- 先在草稿区稳定模板，再发起批量任务
- 大批量任务前先用少量图片试跑，确认模板与 Excel 规则无误
- 每次任务后在日志中心复盘异常与点数变化
