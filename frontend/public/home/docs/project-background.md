# 项目背景介绍

### 1. 业务背景与痛点
在电商日常运营中，商品主图、活动图等通常需要批量加水印。传统做法依赖人工逐张处理，常见问题包括：

- 效率低：同一批图片重复操作多，耗时长。
- 规则不统一：不同成员手工参数不一致，出图风格难以统一。
- 协作难追溯：谁在什么时间改了模板、消耗了多少资源，缺乏清晰记录。

### 2. 目标用户
本系统面向熟练使用表格（Excel）的电商运营团队，典型场景包括：

- 商品上新与批量改图
- 大促活动素材准备
- 渠道分发图批量生成

### 3. 核心方案
系统围绕“模板 + 表格 + 批量任务”设计完整闭环：

- 模板化水印：先定义可复用的文字/图片水印模板。
- Excel 配置驱动：按行配置图片 ID、动态文字、输出路径与命名。
- 批量任务执行：按任务处理图片，生成结果与报表。
- 团队协作管理：成员共享模板、点数和任务记录。
- 点数结算与日志审计：预扣、消耗、返还全流程可追踪。

### 4. 架构特征
- 前端：在浏览器本地执行图片水印渲染（Canvas），并使用本地存储会话保存任务过程数据。
- 后端：负责账户认证、团队与模板管理、任务记录、点数结算、日志查询、支付对接等服务能力。

这种分工保证了批量处理体验与团队管理能力可以同时覆盖。

### 5. 当前能力边界
- 单个批量任务最多支持 1000 张图片。
- 提交任务时按图片数量预扣点数。
- 任务完成后按成功处理数量结算，未实际消耗部分自动返还。

### 6. 业务价值
- 降低重复劳动，提升批量出图效率。
- 统一模板与执行规则，减少人工误差。
- 通过日志与点数流水沉淀协作记录，便于复盘与管理。
